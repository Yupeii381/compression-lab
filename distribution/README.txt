Compression Lab 1.3.0 — Windows x64

ЗАПУСК
1. Распакуйте ZIP целиком в отдельную папку.
2. Запустите CompressionLab.Web.exe.
3. Приложение откроет браузер: http://localhost/co-lab/.

Установка .NET SDK или .NET Runtime не нужна: среда уже включена.
Не переносите один EXE отдельно от папок и DLL этого выпуска.
Оставьте окно приложения открытым. Остановка: Ctrl+C или закрытие окна.

ДАННЫЕ И ОБНОВЛЕНИЯ
Файлы, очередь и результаты сохраняются в:
%LOCALAPPDATA%\CompressionLab\data

Для обновления остановите старое приложение, распакуйте новый выпуск в другую
папку и запустите его EXE. Данные пользователя останутся в указанном каталоге.
Для резервной копии остановите приложение и скопируйте этот каталог.
Старая версия сохраняла data рядом с исходниками. Для её данных используйте:
CompressionLab.Web.exe --data-dir "полный путь к старому каталогу data"

КОДЕКИ
Gzip, Brotli, DEFLATE, RLE, LZMA1.
Внешние DLL находятся в plugins. Собственный плагин с реализацией
ICompressionCodec помещается в plugins/Имя вместе с зависимостями.
Имя сборки: CompressionLab.Codecs.*.dll. После установки перезапустите приложение.
Для разработки кодека нужен SDK; пользователю готового кодека он не нужен.
DLL кодека выполняется с правами приложения, поэтому используйте доверенный код.
Исходники LZMA SDK и сведения о лицензии: https://www.7-zip.org/sdk.html
Описание лицензии также включено в каталог licenses.

ДОПОЛНИТЕЛЬНО
Адрес без номера порта использует порт 80. Если он занят, выберите другой порт.
С --port 8090 адрес будет http://localhost:8090/co-lab/.
Руководство по модулям и собственным кодекам: docs/DEVELOPER-GUIDE.md.
CompressionLab.Web.exe --port 8090
CompressionLab.Web.exe --data-dir "D:\CompressionData"
CompressionLab.Web.exe --no-browser
CompressionLab.Web.exe --restore result.clcs restored.bin
CompressionLab.Web.exe --help

Это локальное приложение. Доступ по сети и учётные записи не предусмотрены.
Архивы .clab из Python-версии не поддерживаются; используется формат .clcs.


ОБНОВЛЕНИЯ
Во вкладке «Обновления» доступна проверка GitHub Releases и установка по кнопке.
Источник: https://github.com/Yupeii381/compression-lab
Для работы нужен опубликованный Release с файлом update-win-x64.json.
Файлы и результаты сохраняются; перед установкой завершите текущий эксперимент.
При ошибке запуска новой версии установщик возвращает прежнюю.
