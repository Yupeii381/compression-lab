# LZMA SDK

Vendor содержит неизменённые файлы C# LZMA SDK 26.04 (Igor Pavlov).
Источник: https://www.7-zip.org/sdk.html
Архив: https://www.7-zip.org/a/lzma2604.7z
Лицензия: public domain; исходное описание включено в Vendor/DOC/lzma-sdk.txt.

Взяты ICoder.cs, Common/CRC.cs, Compress/LZ, Compress/LZMA и Compress/RangeCoder.
LzmaCodec.cs — собственный адаптер приложения, не часть SDK.
